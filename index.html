How this works offline

After you load the JSON once, this app stores the dataset locally in this browser using IndexedDB. The website's shell is cached by the service worker after you visit the GitHub Pages site. The original PDF is opened locally from Files, never uploaded to a server.

What is included vs what still needs engineering

493 indexed records502 extracted page texts456 raw table gridsISA Table 1-1

Implemented arithmetic: interpolation of ICAO ISA Table 1-1, temperature deviation and estimated density using standard thermodynamics; wind vectors; PDM-defined reference-speed multipliers when the underlying chart VSR values are manually supplied; specific range, endurance and simple fuel arithmetic; constant-rate climb/descent training calculations.

Not calculated: PDM engine torque curves; RCR/RFI-dependent MTOW and CFL; VMCG/VMCA and takeoff speeds obtained from performance charts; ground run, takeoff distance, climb gradients, ceiling, driftdown, aircraft-specific cruise charts and landing distances. These require independent digitization, interpolation specification, range checks and validation against the manual.

Automated extraction caveat: 456 table grids were detected, but grid detection can split a source table into multiple pieces or miss individual cells. A grid existing is not proof of correctly decoded row/column meaning. No raw extracted grid is directly used for aircraft performance decisions.
